<h4 align="center">An Android application for searching tracks via iTunes API, previewing track details, listening to samples, and creating custom playlists.</h4>

  <tr>
    <td valign="top">

    <td valign="top">
      <h2>Features 📱</h2>
      <ul>
        <li>Search for tracks via iTunes 🔎</li>
        <li>Saving favourite tracks ❤️</li>
        <li>Viewing track information 📋</li>
        <li>Listening to track samples 🎧</li>
        <li>Creating and editing playlists 📝</li>
        <li>Sharing playlists and tracks 💌</li>
        <li>Theme: Dark | Light 🖤🤍</li>
      </ul>
      <h2>Technologies stack ⚙</h2>
      <ul>
        <li>Single Activity</li>
        <li>MVVM Architecture</li>
        <li>Clean Architecture</li>
        <li>Material Design</li>
        <li>Fragments</li>
        <li>Kotlin Coroutines & Flow</li>
        <li>Navigation Component</li>
        <li>Retrofit2</li>
        <li>Room Database</li>
        <li>Koin</li>
      </ul>
